# Qahtan Al Oud — Research Website

A lightweight bilingual (English/Arabic) GitHub Pages site for research on Bitcoin forensics and historical blockchain analysis.

## Structure
- `index.html`: English homepage
- `ar/`: Arabic homepage
- `projects/`: English and Arabic project summaries
- `assets/site.css`: shared responsive styling
- `sitemap.xml` and `robots.txt`: basic search indexing files

## Publishing
This repository is configured for GitHub Pages. The site uses relative-root asset paths and canonical URLs under https://qahtan58.github.io/.

Project descriptions are intentionally limited to claims documented in their public repository READMEs. See each linked repository for primary artifacts, methods and limitations.
